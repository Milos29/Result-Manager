###Result Manager

Result Manager is a simple and intuitive desktop application designed to rank students of Software Engineering at the School
of Electrical Engineering, University of Belgrade based on their coefficients. It's written in Python using Tkinter.

##Features

Rank Students by Coefficient: Automatically ranks students based on their academic performance using coefficients.

User-Friendly Interface: Designed for simplicity, making it easy for anyone to manage student results effectively.

Multiple Result Sources: Add results from PDF files or paste them directly into the application.

Semester and Subject Selection: Specify the semester, subject, and exam period when adding results.

Result Management: Edit or delete previously saved results with ease.

##How to use

#Adding Results

Open the application.

Select an installed PDF file containing student results or paste results manually.

Specify the semester, subject, and exam period.

Save the results to update the ranking.

#Altering Results

Previously saved results can be modified or removed from the system for accuracy and consistency.
